Background playback acceptance
  • Healthy HTML audio stays attached while the page is hidden.
  • Media Session actions persist through state updates; optional API failures are tolerated.
  • Transient reconnects repeat while browser execution is available. Explicit pause survives reconnection.
  • Desktop rejection, revocation, stream end and Disconnect stop retries.
  • Physical Android screen-off, call interruptions and battery-manager behavior remain unverified.

A frozen or terminated page cannot run JavaScript. Media Session does not guarantee that Chrome or Android keeps a process alive. A powered-off phone cannot receive live audio.
