# Fonts

- Body text uses Liberation Sans 2.1.5 (Red Hat, SIL Open Font License 1.1, see `LICENSE`). Titles use Nunito Bold (SIL OFL 1.1, see `NUNITO-LICENSE`). Both are the subsets from the leet landing page, so the two sites share one type system.
- The hand-drawn scenes use Excalifont (SIL OFL 1.1, see `EXCALIFONT-LICENSE`). This file is the Latin subset that `@excalidraw/excalidraw@0.18.0` ships as `dist/prod/fonts/Excalifont/Excalifont-Regular-a88b72a24fb54c9f94e3b5fdaa7481c9.woff2`.
