# Step 06: Dev Mode And Tests

## Goal

Make the app easy to verify while keeping normal UI clean.

## Build

- Add Settings with persisted Dev Mode.
- Show Dev tab only when Dev Mode is on.
- Add graphs for latency and setup time.
- Add event logs for joins, approvals, errors, and connection changes.
- Add npm scripts for type, core, desktop, Android emulator, and latency tests.

## Done When

- Dev Mode persists.
- Dev tab shows current-session stats only.
- Functionality tests cover session rules.
- Android emulator script can run app-level checks.
- Real device latency remains the final acceptance check.
