# Step 04: Desktop UI

## Goal

Make desktop control clean and simple.

## Build

- Use shadcn-style components.
- Keep copy short.
- Add Start and Stop.
- Add QR card.
- Add LAN toggle.
- Add pending, connected, denied, and disconnected device states.
- Add sharing, disconnect, and unblock actions.

## Done When

- Main screen shows only what the desktop user needs.
- Device states are clear.
- Actions are easy to find.
- No large explanatory text is needed.
